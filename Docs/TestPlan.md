## 3.1 本工程踩到的测试方法坑

1. **`-nullrhi` 不能用于本工程的运行时冒烟**：静态网格就绪等待永远不满足，世界卡在启动阶段，玩家不生成。
   必须带渲染运行（可小窗口 `-resx=960 -resy=540`）。
2. **`Build.bat` 在 Git Bash 里直接调用会返回"拒绝访问"**（退出码 1，972ms 内失败）。
   改用 PowerShell 调用，并先把引擎自带 `DotNet\6.0.302\windows` 加进 `PATH`。
3. **`Tee-Object` 写出的日志是 UTF-16LE**，`grep` 读不到内容 → 需要 `iconv` 或改用 `Out-File -Encoding utf8`。
4. **游戏实例里 `unreal` 模块没有 `EditorLevelLibrary`**；取世界要用
   `unreal.load_object(None, '/Game/.../Map.Map')`，再喂给 `GameplayStatics`。

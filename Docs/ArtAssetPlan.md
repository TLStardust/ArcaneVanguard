## 1. P0 阻断项（没有它们 M3–M5 跑不通）

### 1.1 敌人：Arcane Guard 奥术守卫（M3 / M5）

**✅ 已采购（2026-10-23）：`Dark Knight - Male and Female`**
<https://fab.com/s/b03de798c900> —— 详见 `AssetRegister.md` 登记项。

| 项 | 情况 |
|---|---|
| 模型 + 骨架 | ✅ 有，**Mannequin Skeleton for UE4 / Quinn for UE5 双兼容** → 导入时 Skeleton 选 `SKE_Wizard`，骨名直接对上，**不需要 IK Retargeter** |
| 动画 | ✅ **52 个全齐**：Idle×2 / Walk×16 / Run×6 / Attack×3 / HitReact×8 / Death×1 / Crouch×16 |
| 模块化 | ✅ 分件（头盔/盔甲/裤/头/手套/靴），男/女双版本 → 敌人变体几乎零成本 |
| 材质 | ✅ 可调 color / roughness / metallic / **emissive** → 改成"奥术守卫"的关键 |
| 风格 | ⚠️ 暗黑重甲骑士 ≠ 奥术守卫，靠材质改色 + emissive + Niagara 符文弥补 |
| 剑系动画 | ⚠️ Attack×3 是剑系，**不能给玩家用**（玩家是法杖） |

**集成时还要做**：敌人 AnimBP（可基于 `AnimBP_Wizard_ThirdPerson` 改造）+ 骨骼 socket（`Muzzle`/`Hit`）+ 奥术材质实例。

> **选型标准回顾**：敌人骨架选 Epic skeleton 兼容是对的 —— 现在玩家的动画资源可以反向复用给敌人
> （例如让奥术守卫放玩家的 `Cast_Spell` 技能），一份投入两份产出。

#### 若需要第 2 种敌人（可选扩展）

优先从同作者/同系列的兼容装甲套里挑（页面列了 Gothic Knight、Fallen Knight、Shadow Knight、
Wicked Knight、Rogue Knight、Alatus Knight 六个兼容套装），骨架同源，导入成本最低。

### 1.2 普通攻击连击动画（M3）

已在 `TechnicalDesign.md` §5.8.1 调研完毕，**结论**：

| 优先级 | 候选 | 价格 | 说明 |
|---|---|---|---|
| **先拿** | `Mega Spear Animation Pack` | **免费** | 219 动画，页面明示 UE4 Mannequin 命名 → 与 `SKE_Wizard` 骨名一致，**不需要 IK Retargeter**。Fab 已转免费 |
| 备选 | `Essential Magic Staff Animation Pack` | $37.61 | 法杖专用连击最完整（attack_10/11/12），含 `ik_hand_gun` 适配 |
| 免费备选 | Mixamo `staff attack` / `attack combo` | 免费 | 需 IK Retargeter（链路已验证），多为单段需自己拼 |

搜索关键词手册：`Docs/AV023_SearchKeywords.md`
**下载/购买属 L4，必须由负责人执行。**

**接入前必须处理的两个已知问题**（见 §5.8.1）：
1. `bKeepWeaponUpright` 竖直约束会掰直攻击动画里的武器姿态 → 播放攻击动画时需按动画类型关闭
2. 长枪动画是双手持握，法杖现只挂 `weapon_r` 单点 → 左手会握空（先接受，后续加 `weapon_l` 第二挂点）

### 1.3 基础 VFX（M3 / M4）

## 5. 授权红线（必须遵守）

1. **所有资产必须登记到 `Docs/AssetRegister.md`**（§5.4 要求）：来源链接、许可证、是否需署名、骨架兼容性、导入日期。
2. **禁止解包商业游戏资产**（霍格沃茨之遗等）——侵权，且作品集不可用。理由已在对话中说明，不重复。
3. **`Content/Wizard` 的授权尚未闭合**：全包带 `UECANDY.COM` 字符串，9 个动画带 `mixamo.com`。**M7 前必须确认**（AV-012）。
4. 付费包的许可通常是"可商用但不可再分发"——放进作品集视频/截图一般没问题，但**不要把别人的 .uasset 直接上传到公开仓库**。
5. 免费包注意区分 **CC0**（无需署名）与 **CC-BY**（需署名）——后者要在 README 里列署名。

## 6. 建议搜集顺序（按依赖，不按喜好）

```
第 1 批（解锁 M3，最急）
  ├─ ✅ Dark Knight - Male and Female（敌人，已采购）
  ├─ Mega Spear Animation Pack（免费，普通攻击连击）
  └─ 1 个通用魔法 VFX 包（弹体/命中/施法/消散）

第 2 批（解锁 M4）
  ├─ 技能特效：范围指示器 Decal 材质、冰霜材质、星陨落石 Mesh
  └─ 技能图标 ×4

第 3 批（解锁 M5）
  ├─ 遗迹模块化环境包
  └─ Poly Haven HDRI

第 4 批（解锁 M6/M7）
  ├─ Kenney UI + 字体
  ├─ Sonniss 音效包
  └─ 后处理/震动曲线（自制，零成本）
```

> 每批到货后先做「导入 → 登记到 AssetRegister → 跑通对应里程碑」再买下一批。
> 一次买齐很容易出现"包之间风格不搭""骨架不兼容""用不上"的浪费。

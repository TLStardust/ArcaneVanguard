## 5. 踩过的坑（务必先看，能省大量时间）

1. **UE Python 读布尔属性要去掉 `b` 前缀**：`bKeepWeaponUpright` → `keep_weapon_upright`。
2. **`unreal.AnimationBlueprintLibrary` 未暴露给 Python**（commandlet 和编辑器里都没有），
   且 `UAnimSequenceBase::Notifies` 是 `protected` 不可写 → **无法用脚本给动画加 Notify**。
3. **增量编译"4 个动作在 0.06 秒内全部失败且零编译器输出"** = PCH/依赖图状态失配，不是代码问题。
   解决：`-Clean` 后重建。
4. **锁屏（`Get-Process LogonUI` 有进程）时不要跑带渲染的游戏截图**：会出黑图或触发
   `DXGI_ERROR_DEVICE_HUNG`。编译 / commandlet / 改文件不受影响。
5. **`USkeletalMeshComponent.get_single_node_instance()` Python 未暴露**；
   验证播放状态只能用日志或 `get_animation_mode()`。
6. **验证瞬时状态别轮询**：桥接调用有延迟，3 秒动画两次调用就错过了。**看日志时间戳最可靠**。
7. `Rotator.rotate_vector`、`BlueprintGeneratedClass.get_super_class` 在 Python 中**不存在**。
8. `UAnimSingleNodeInstance::GetCurrentAsset()` 是**非 const**，用 const 指针接会报 C2662。
9. **用 Edit 插入大段代码后，务必 `grep -n "^void A...::"` 核对函数列表** —— 我曾把新签名贴到旧函数体上造成重复定义。
10. **老式 `PlayerInputComponent->BindKey` 与 Enhanced Input 可以共存**，做调试按键不需要额外建 IMC/IA 资产。

## 6. 未完成项（下一手工作）

### 6.1 KI-013：`Cast_Spell_01` 杖身穿掌（P1）

- 现象：法杖位置和朝向都对，但**手指是张开的，杖身从掌心穿过**。
- 根因：技能动画来自 **Mixamo**，录制时手上没有武器。
- **不能靠"隐藏法杖"解决**（这是唯一保留法杖的动作）。
- 候选方案：
  - **A4 手指弯曲层**（推荐）：在 `AnimBP_Wizard_ThirdPerson` 的 AnimGraph 加
    `Transform (Modify) Bone` 节点，对五指骨骼按固定角度弯曲。
    ⚠️ 需改 AnimBP 图，无法纯脚本完成；**动手前先备份 `AnimBP_Wizard_ThirdPerson.uasset`**。
  - **A3 换持杖动画**：成本高，但治本。
- 相关文档：`Docs/GripTest_20261021/README.md`

### 6.2 AV-023：缺少"普通攻击"连击动画（P1）

- 现状：现有 17 个动画**全是技能 / 移动 / 死亡，没有任何普通攻击连发**。
- 获取路径与架构要求见 `Docs/TechnicalDesign.md` §5.8。
- 注意：连击需要 `AnimMontage` + Section + 输入缓冲 + ComboWindow，
  **不是"三个动画挨着播"**。已有 `DebugAnimations` / `DebugPlayAnimation` 可当验证脚手架。
- 本工程两个有利条件：骨架是 UE4 Mannequin 命名；Mixamo→`SKE_Wizard` 重定向已被验证可行。

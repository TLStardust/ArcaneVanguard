# P1 竖直约束验收 —— 2026-10-22

- 目的：确认 `bKeepWeaponUpright` 能解决"施法时法杖上下颠倒"（KI-014）
- 方式：`-game` 实跑 + 运行时冻帧截图，相机 `arm=360` / `do_collision_test=False` / 角色 yaw=90
- 结论：**通过**。三个姿势下法杖均保持竖直、水晶朝上，且握点始终贴合手骨

## 已知代价（P1 的固有局限）

`Magic_Attack` 是前刺动作，法杖仍保持竖直、不跟随前倾。这是"强制竖直"的必然结果。
拿到持杖动画（P3）后，把 `bKeepWeaponUpright` 设为 `false` 即可回到动画驱动。

## 4. 踩过的坑（必读，能省几小时）

| 坑 | 症状 | 解法 |
|---|---|---|
| **UBT 秒退且零诊断** | 所有编译动作 0.06s 内全失败 | 查 `%APPDATA%\Unreal Engine\UnrealBuildTool\BuildConfiguration.xml` 里的 `<bAllowUBAExecutor>false</bAllowUBAExecutor>`，删掉。**重启机器无效** |
| **`build_manual.sh` 不删旧 obj** | 编译中断后 `link` 报 `LNK2019 无法解析的外部符号`，像函数没实现 | 脚本已修（编译前 `rm -f` 同名 obj）。排查手法：比对 obj 与源文件时间戳 |
| **改 `.h` 不重跑 UHT** | `C2143 在 class 前` + `"XXX" 不是 "AInfo" 的成员` | 手动跑 UHT（见 §1） |
| **源码注释里用 emoji** | MSVC 报 `C2143` / `C4430`，看起来像整个类没定义 | 注释只用 ASCII，用 `[!]` 代替 `⚠️` |
| **`SetActorEnableCollision(false)`** | 之后怎么改组件碰撞都读回 0，`GetMass()` 停在 1.0 | **Actor 级开关优先级高于组件级**。删掉那行，改用通道响应 |
| **`GetCollisionEnabled()` 返回 0** | profile 不是 `"Custom"` 时会去查预设，查不到就返回 NoCollision | 钉死 `"Custom"` + 显式设字段，或改用 `get_collision_object_type()` 验证 |
| **`UBlackboardComponent::SetValueAsBool` 返回 void** | 写成 `if (BB->SetValueAsBool(...))` 报 `C2451` | C++ 里返回 void（Python 才是 bool），判断键存在要用 `GetKeyID` |
| **参数名 `bHidden`** | UHT 报 shadowing 错误 | `AActor` 已有同名成员，用 `bInHidden` |
| **编辑器卡在「是否等待 ZenServer？」** | 桥接一直不响应，进程 `Responding=True` | 杀 `zenserver.exe` + 编辑器，重启（ZenServer 会自动拉起，约 40s 就绪） |
| **编辑器开着时 link 失败** | `LNK1104 无法打开 DLL` | 必须关编辑器。用 `WM_CLOSE`（等价点 ×，安全） |
| **Notion 表格改不了** | `update_content` 报 `No matches found` | 表格是单块、行不是独立 block，只能整页 `replace_content` |
| **Notion `page_id` 参数位置** | 放最后报 `must have required property 'page_id'` | 必须放在参数对象**最前面** |

## 5. 关键设计决策（改代码前先看）

| ADR | 内容 | 为什么不能随便改 |
|---|---|---|
| **ADR-004** | ASC 挂在 Character | 迁 PlayerState 会牵连所有技能与属性 |
| **ADR-005** | `ApplyDamage` 是伤害唯一入口 | 绕过它 = 钳制失效 + 无法统一加 Authority |
| **ADR-011** | 自定义碰撞通道 `Weapon`/`Enemy` | `Enemy` 通道 `DefaultResponse=Block`，球扫必须用 `SweepMultiByObjectType`，不能用 `SweepMultiByChannel` |
| **ADR-012** | GA 分层：C++ 基类管流程、蓝图只填数据 | 基类改动影响所有技能，需要回归测试 |

**握持校准**：`StickSocket` 在 `hand_r` 上带 **−124cm** 偏移，`CombatGripOffset = (0,0,90)`、`CombatGripInterpSpeed = 10.0`。**不要切 `weapon_r` 挂点**（会推翻整套校准）。
